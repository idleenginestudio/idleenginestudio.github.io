# idleenginestudio.github.io

Idle Engine Studio 的官網：https://idleenginestudio.github.io/

- 首頁：`index.html`
- 隱私權政策：https://idleenginestudio.github.io/privacy/ （火柴建築師、麻將三國戰、氣運復仇者、青紅燈）

首頁直接改 `index.html`、`style.css`。隱私權政策由 `gen_privacy.py` 產生，改內容請改 `gen_privacy.py` 後執行 `python3 gen_privacy.py`。
之後 AdMob 要求的 `app-ads.txt` 也放在這個 repo 的根目錄。
